# Bundled third-party asset licenses

This directory ships the license texts for the third-party **assets** bundled
inside `QT-PyQt-PySide-Custom-Widgets` (icon sets and fonts). It travels with the
package so the attribution/notice requirements of those licenses are satisfied
wherever the package is installed.

For the full inventory (including pip-installed runtime dependencies, which are
**not** bundled), see `../THIRD_PARTY_NOTICES.md`.

| Bundled asset | Location in package | License | License text |
|---|---|---|---|
| **Font Awesome Free** — icons | `Qss/icons/font_awesome/` | **CC BY 4.0** (icons), SIL OFL 1.1 (fonts), MIT (code) | [`CC-BY-4.0.txt`](CC-BY-4.0.txt) · [`OFL-1.1.txt`](OFL-1.1.txt) |
| **Material Design Icons** | `Qss/icons/material_design/` | Apache-2.0 | [`Apache-2.0.txt`](Apache-2.0.txt) |
| **Feather** | `Qss/icons/feather/` | MIT | [`Feather-MIT.txt`](Feather-MIT.txt) |
| **Rosario** (app font) | `Qss/fonts/Rosario/` | SIL OFL 1.1 | [`OFL-1.1.txt`](OFL-1.1.txt) (also `Qss/fonts/Rosario/OFL.txt`) |
