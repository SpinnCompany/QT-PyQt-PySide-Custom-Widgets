# External-contribution audit (GPLv3 → LGPLv3 relicense)

**Date:** 2026-07-23
**Purpose:** Determine, precisely, which external (non-owner) contributions still
have surviving lines in `HEAD`, so the relicense's contributor-consent step can be
scoped. Part of `../design/lgpl-relicense-plan.md`.

> **Not legal advice.** This is an engineering fact-finding record. The
> de-minimis / non-copyrightability assessments below must be confirmed by
> qualified legal counsel before they are relied on for the relicense.

## Method

- Owner identities are consolidated via `.mailmap` (canonical:
  `Khamisi Kibet <kibetkhamisi@gmail.com>`). Verified with `git shortlog -sne`:
  **408 / 414 commits (~98.6%)** are the owner; 6 commits across 5 external
  identities.
- For each external identity, an **authoritative full-tree `git blame` sweep**
  counted lines in the current tree still attributed to that author (blame follows
  content across renames, so this catches survival even when the original file was
  renamed/regenerated):

  ```
  git ls-files -- '*.py' '*.ui' '*.scss' '*.qss' '*.json' '*.md' '*.txt' '*.cfg' '*.toml' \
    | while read f; do git blame --line-porcelain HEAD -- "$f"; done \
    | grep '^author-mail ' | sort | uniq -c
  ```

### Surviving lines (both non-protectable)

**youngsikshin — 8 lines, all `import` statements** in the vendored `iconify/`
engine (from the "modify import path" / "support win" commits):

```
Custom_Widgets/iconify/anim.py
    from Custom_Widgets.iconify.qt import QtCore, QtGui
Custom_Widgets/iconify/core.py
    from Custom_Widgets.iconify.anim import GlobalTick
    from Custom_Widgets.iconify.path import findIcon
    from Custom_Widgets.iconify.qt import QtCore, QtGui, QtSvg

Custom_Widgets/iconify/fetch.py
    import Custom_Widgets.iconify as ico
    from Custom_Widgets.iconify.qt import QtCore, QtXml
```

Assessment: these are **package-dictated import statements** — given the package
layout `Custom_Widgets.iconify.*`, there is only one correct way to write each
import. Expression merges with function (merger doctrine); no creative choice
exists. Textbook **de minimis / non-copyrightable**.

**Théo Brunet — 3 lines** in an **auto-generated** example UI module,
`examples/PySide6/QCustomQPushButton/ui_interface.py`:

```
    self.pushButton = QCustomQPushButton(self.centralwidget)
    self.pushButton_2 = QCustomQPushButton(self.centralwidget)
    self.pushButton_3 = QCustomQPushButton(self.centralwidget)
```

Assessment: `ui_interface.py` is **generated by the UI compiler** from the sibling
`.ui`. The contribution was changing `QPushButton` → `QCustomQPushButton` in the
example's `.ui`; the surviving lines are the regenerated widget instantiations —
tool-generated boilerplate, not hand-authored expression. **De minimis /
non-protectable**; can also be trivially cleared by regenerating the file (see
below), which re-authors the generated artifact under the owner.

## Conclusion

- **4 of 5 external contributors** have **no surviving lines** — nothing to clear.
- The **11 surviving lines** are all either package-dictated imports or
  tool-generated boilerplate, with **no protectable expression**.
- Therefore the GPLv3 → LGPLv3 relicense is **effectively unblocked** on the
  contributor-consent axis, **pending counsel's confirmation** of the de-minimis
  calls. Belt-and-suspenders consent can still be sought (see
  `consent-tracking-issue.md`), and the two survivor sets can optionally be
  cleared outright (regenerate the one example `ui_interface.py`; the iconify
  imports cannot be written any other way, so a rewrite is a no-op).
